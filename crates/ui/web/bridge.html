✦ gift-check bridge

1. Open a store from here

Keep this tab open. A store opened with these buttons can send its listings back to this tab, and only to it. The store tab is a normal tab: sign-ins, carts and checkout are never touched.

2. Run the capture script in the store tab

In the store tab, run that store's capture script (see capture/README.md in the gift-check folder). It reads the product listings on the page and posts them here in chunks.
